# STM32F413ZGT
Драйвер для взаимодействия микроконтроллера STM с флеш-памятью через SPI + отладка через UART

# Сборка прошивки
1. Сгенерируйте код для микроконтроллера STM32F413ZGT(6), например, через CubeMX
2. Скачайте директорию
3. Замените папку Core на скаченную
4. Соберите проект через Make
5. Загрузите файл .bin или .hex в микроконтроллер STM32F413ZGT
6. Для отладки используются пины PE2 (RX) и PE3 (TX)
