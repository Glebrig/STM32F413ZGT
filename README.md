# STM32F413ZGT
Драйвер для взаимодействия микроконтроллера STM с флеш-памятью через SPI + отладка через UART

# Сборка прошивки
1. Скачайте директорию
2. Соберите проект через Make
3. Загрузите файл .bin или .hex в микроконтроллер STM32F413ZGT(6)
4. Для отладки используются пины PE2 (RX) и PE3 (TX)
